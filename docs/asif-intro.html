ASIF — explain it as if I were…

Name any topic, add one tag, and get a researched, source-annotated, horizontal-swipe web slide deck pitched at exactly one audience: a 5-year-old, an undergrad, or a researcher.

How to trigger it

Put the tag anywhere in your message, any capitalization. Everything else is the topic.

Explain to me CRISPR. ASIF-KIDDO asif-bs: how do vaccines work? ASIF-PHD diffusion models

Several tags in one message build one deck per tag, simplest first. Ask in another language and the slides are written in it.

Follow-ups

  • "go deeper" moves the last deck up one level; "simpler" moves it down.
  • "now ASIF-PHD" (a tag alone) re-explains the previous topic at that level.
  • Ambiguous topic ("Explain Mercury")? It asks one short question, then starts.
  • Ordinary explanation requests without a tag are not touched by the skill.

The three modes · same start ("what is it?"), different ceilings

ASIF-KIDDO

A curious 5-year-old

Can say what it is and why it matters.
ASIF-BS

A smart undergrad

Knows calculus and stats, not this field.
ASIF-PHD

A researcher, new to the topic

Reads Nature papers, from a nearby field.

Saved on the Desktop

Each deck is one HTML file written to ~/Desktop/ASIF/<topic>-<mode>/index.html, e.g. crispr-kiddo, vaccines-bs, diffusion-models-phd. It opens in your browser: ← → to flip, ESC for overview, P for presenter mode.
